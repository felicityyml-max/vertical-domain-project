各阶段关键动作和交付物 / 通过标准
每个阶段要做什么、交出什么、过不过的判定标准（Gate）。
S1
想法提出
形式：提交
关键动作
提出「想法卡」（≤1 页）：问题、初步目标、期望节奏。
来源不限：老板、产品、引擎、模型等。
交付物 / 通过标准
交付物① 想法卡
交付物② 发起方团队负责人指定调研 POC
Gate发起方团队负责人评审通过，想法卡进入立项池
S2
项目预沟通
形式：会议
关键动作
PMO 组织，发起方与必要相关方参会：判断是否值得进入调研，明确调研范围、相关方清单、调研责任人与时间盒。
交付物 / 通过标准
交付物预沟通结论：进入调研 / 暂缓 / 合并到在途项目 / 关闭
交付物调研范围与相关方清单
Gate结论需有明确理由并留档
S3
可行性调研-内部
形式：调研
关键动作
定向卷入内部相关方背书：评测、产品、引擎、模型、生态、运营、跨团队合作（按相关度选派，每方 1 人对接）。
交付物 / 通过标准
交付物立项文档（六要素）
1. 问题与背景
2. 目标与基线（可量化验收口径）
3. 定位与打法
4. 资源与里程碑
5. 主 R 与团队分工、协作机制
6. 验收标准（含数据来源与评测方案）
Gate六要素齐全，各相关方明确「支持 / 有保留支持 / 反对」及理由
S4
可行性调研-外部
形式：调研（与 ③ 并行）
关键动作
确认外部依赖：司内合作方（如 fit）、司外合作方（如京东）的接口、数据、排期是否可兑现，规划里程碑。
交付物 / 通过标准
交付物并入立项文档六要素（外部依赖可兑现性写入「资源与里程碑」）
Gate外部依赖有明确排期或书面结论
S5
项目目标预审
形式：对齐
关键动作
就目标与验收口径与老板对齐，先行消除分歧，避免评审会上翻案。
参照目标预审自检卡（见 6）
交付物 / 通过标准
Gate目标与验收口径与老板对齐
OK → 进入正式立项
不 OK → 回退调整或放弃立项
S6
立项评审会
形式：会议
关键动作
PMO 组织，季度常规窗口期集中评审；外部机会可穿插实时立项（走临时立项通道）。
交付物 / 通过标准
交付物① 项目是否通过
交付物② 六要素是否通过
交付物③ 明确目标对账频率
交付物④ 明确项目是否自闭环 or 需 PMO 参与
不通过 →退回补充（限时 1 周）或关闭并留档理由

5
贯穿性机制
不绑定单一阶段、贯穿全流程的三条机制。

M1临时立项通道

为适应业务野蛮生长，对外部机会 / 突发需求可以不等季度窗口，临时发起立项流程。
· 临时插入项目须注明挤占哪个在途项目
· 若准入插入项目，需重新更新垂类项目优先级排序

M2垂类风险管理机制

风险与依赖以 list 形式周更，卡点在周会上仲裁，阻塞项同步到垂类风险跟踪表。

建议：延期 ≥2 次同步至 PMO 更新至风险跟踪表。

M3目标对账机制

按约定节奏对账目标进度，未达标项目需给出明确结论，禁止无结论顺延。

建议：至少季度第 4–5 周做一次中期对账，达成度 <50% 提前预警；目标变更须走评审，单季度 ≤1 次，变更留档。

T5项目目标预审自检卡（准入参照）

自查项标准
① 四要素齐全 指标名与计算口径 · 基线值 · 目标值 · 达成时间
② 目标是否「够高」 原则：跳一跳够得着。目标改善幅度建议不小于同类项目历史中位幅度，且不低于垂类自身历史最好水平。
目标类型强度下限说明
竞对差距类
GSB / SBS / 分位差		差距收敛 50%
或绝对改善 ≥10pp		若基线差距已 <10pp，则必须定为「追平或反超」，不接受"小幅缩小"。
准召类
准确率 / 召回率		基线 <60%：提升 ≥+10pp
基线 60–80%：提升 ≥+5pp
基线 >80%：提升 ≥+3pp 或达竞对水位		同一项目不得只提准召中的一个：只优化召回导致准确率下滑，须同时给出护栏指标。
体验负向类
劝退率 / 无结果率 / badcase 率		相对下降 ≥20%
或绝对下降 ≥5pp		须注明统计口径（1 分占比 / 分位 / 端效），口径与基线必须同源。
能力建设 / 交付类
上线功能、引入资源		必须绑定结果指标如健康档案上线一期 MVP 配套记忆准确率。
③ 否决清单
命中任一条
不进正式立项会		 1. 目标缺失或"待定"——如"目标下周产出""待摸底后确定"。
2. 基线未实测——基线来自估算、拍脑袋或"最近一次通用题库"等非本项目口径的数据。
3. 目标表述模糊——用「xx%」「有提升」「优化」代替具体数值。
4. 目标过低——低于强度下限，或低于该垂类历史最好水平（回退型目标）。
5. 只有过程指标、无结果指标——只有"完成标注 N 条""训练 N 版""接入 N 家"。
6. 目标依赖未落地的外部依赖——fit / 京东尚未握手、无排期，目标视为无效。
7. 验收口径未定——没有说明评测集、量级、评测方式，结项时无法判定。
